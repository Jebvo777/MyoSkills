# MyoSkills

MyoSkills — приложение для домашних занятий по назначениям миотерапевта и совместного ведения пациента. Пациент получает маршрут упражнений, отправляет видео и видит комментарии. Специалисты ведут приёмы, фотопротокол, направления и переписку. Администратор управляет доступом, библиотекой и содержимым сайта.

Выпуск от 27.10.2026 переводит проект в рабочий режим: быстрые служебные входы, вымышленные отзывы, установочные аккаунты и подставные видео исключены. Визор пациента обновлён по макету Figma, графика распределена по смысловым блокам, персонажи получили отдельную анимацию. Показатели кабинета берутся из данных пациента.

**Для обновления существующего сайта обязательна миграция БД. Перед полной заменой сохраните `config.local.php` и всё содержимое `storage/files`. В приложенном исходном дампе единственный администратор относится к отключаемым исходным аккаунтам: создайте отдельного настоящего администратора до миграции.**

Пошаговая установка и замена файлов: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). В готовом архиве эта инструкция также находится снаружи папки проекта под именем `INSTALL-UPDATE.md`.

## Требования к серверу

- PHP 8.1 или новее; расширения `pdo_mysql`, `mbstring`, `fileinfo`, поддержка сессий и JSON.
- MySQL 5.7 с InnoDB и `utf8mb4`.
- Apache 2.4 с действующими правилами `.htaccess` и возможностью записи PHP в `storage/files` и `storage/logs`.
- HTTPS для рабочего сайта и записи видео с камеры браузера.

Composer, Node.js, Redis, WebSocket и сборка ресурсов на сервере не нужны. Клиент использует обычные JavaScript ES modules, локальные стили, шрифты и графический движок. `mod_rewrite` не требуется: API доступен через `api.php?action=...`.

## Существующая установка

1. Сохраните актуальную резервную копию БД, локальную конфигурацию и загруженные файлы за пределами публичного каталога.
2. Создайте настоящего администратора. Без SSH можно зарегистрировать отдельный новый аккаунт обычной формой, вписать его email в `database/create_admin_from_account.sql` и импортировать этот файл через phpMyAdmin. Скрипт работает на структуре БД до миграции и не повышает аккаунт с клинической историей.
3. На время замены остановите приём новых данных. В выбранную существующую БД импортируйте `database/upgrade_20261027_production.sql`.
4. Замените код содержимым папки `MyoSkills` из архива. Верните сохранённый `config.local.php` и файлы в `storage/files`, сохранив новые правила `.htaccess`.
5. Войдите своим аккаунтом. Администратор заполняет реальную библиотеку, а миотерапевт назначает пациентам актуальные упражнения.

Миграция не удаляет клиническую историю или реальные аккаунты. Она архивирует распознанные исходные образцы, выключает их доступ и скрывает соответствующие упражнения. Назначения архивных упражнений приостанавливаются. Старый исходный дамп не следует импортировать вместо обновления: он не содержит последующих изменений рабочего сайта.

## Новая установка

Создайте пустую БД в панели хостинга, загрузите проект, скопируйте `config.example.php` в `config.local.php` и заполните своё подключение. Импортируйте `database/install.sql` через phpMyAdmin. Этот файл создаёт схему, шесть категорий упражнений и нейтральное содержимое сайта; аккаунтов и медицинских материалов в нём нет.

Если доступен SSH:

```bash
php tools/install.php
php tools/create_admin.php owner@your-domain.ru
```

Пароль администратора задаётся интерактивно. Для phpMyAdmin без SSH используйте регистрацию нового отдельного аккаунта и `database/create_admin_from_account.sql`, как описано выше.

## Основные возможности

- Кабинет пациента: назначения, видеообразцы, шаги, таймер, отметка занятий, загрузка и запись видео, дневник, отчёт, игровые показатели и фотопротокол.
- Кабинет специалиста: команда пациента, приёмы и вложения, проверка выполнения, направления, план и сроки лечения, диалоги и уведомления.
- Администрирование: пользователи, верификация документов, библиотека упражнений, публикация отзывов, страницы, контакты и материалы сайта.
- Русский и английский интерфейс, адаптация к узкому экрану, управление анимацией, локальные 3D-сцены и статические варианты при недоступности WebGL.

Полная карта функций и ролей: [docs/FEATURES.md](docs/FEATURES.md). Устройство приложения: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Рабочее содержимое и интеграции

Реальные видео, инструкции к упражнениям, квалификационные документы, контакты и реквизиты добавляет владелец проекта. Для публикации упражнения требуются доступное загруженное видео, описание и шаги. Без этих материалов оно сохраняется как черновик. Пустой раздел не заполняется вымышленными данными.

Внутренние уведомления сохраняются в БД. Почтовая доставка включается через `mail.enabled`, действующий адрес отправителя и PHP `mail()` у хостера. Пока канал отключён, восстановление пароля по почте обозначено как недоступное. Напоминания запускаются через `tools/reminders.php` по cron.

Сервис не перекодирует загруженное видео. Поддержка конкретного MP4, WebM или MOV зависит от браузера и кодека. Внешняя оплата, SMS/MAX и автоматическая медицинская оценка видео не подключены; выполнение проверяет специалист.

## Файлы и проверки

`app/` содержит API и права доступа; `assets/` — интерфейс и графику; `database/` — установку и миграции; `tools/` — служебные CLI-команды; `docs/` — документацию. Секреты и загруженные пользователями материалы исключены из Git. Исходный SQL-дамп пользователей не входит в публичный репозиторий и архив приложения.

По заданию заказчика упаковка предшествует базовым проверкам синтаксиса. Полный регресс, запуск миграции на рабочем сервере и проверка доставки писем в текущем выпуске не заявлены. Границы проверки описаны в [docs/QA.md](docs/QA.md); фактический результат синтаксической проверки фиксируется отдельно после упаковки.
