# MyoSkills

Звёздное дитя реализовано как цельная неоновая фигура с анимацией приветствия, мерцанием созвездий и кнопкой «Помахать». Описание: `docs/STAR-CHILD.md`.

Визуальная доработка 22.10.2026: исправлены блоки по присланным скриншотам, добавлены четыре иллюстрации, карусель шести демонстрационных отзывов и настоящие 3D-сцены из присланной заставки. Подробности: `docs/VISUAL-REVISION.md`. Для этого обновления SQL не нужен.

Выпуск 22.10.2026: весь интерфейс приведён к переданному Figma UI-kit — TT Firs Neue / PT Root UI, палитра, карточки, поля, кнопки, переключатели и навигация. Правки из документа включены; описание — в `docs/UIKIT.md`.

Полное PHP/MySQL приложение для shared-хостинга: широкий тёмный лендинг, неоновые зубные голограммы, кокпит пациента, кабинеты специалистов и администрирование. Мерцающие звёзды сопровождают все разделы, а приборы кокпита показывают реальные показатели пациента.

## Установка в /mio

1. Выберите PHP 8.2 или новее в панели хостинга. Нужны PDO MySQL, mbstring, fileinfo и sessions.
2. Распакуйте содержимое архива в каталог `mio` внутри корня сайта. `index.php` должен оказаться в `mio/index.php`, а не в дополнительной вложенной папке.
3. Для установки с тестовыми данными в phpMyAdmin выберите пустую базу `system404_mio` и импортируйте один файл `database/install_with_demo.sql`. Он содержит и таблицы, и демонстрационные записи. Для рабочей базы без примеров используйте только `database/schema.sql`. Отдельный `seed.sql` оставлен как альтернативный вариант; после объединённого скрипта его импортировать не нужно.
4. В установочном архиве `config.local.php` уже заполнен данными подключения. В GitHub его нет. При установке из GitHub скопируйте `config.example.php` в `config.local.php` и внесите пароль базы локально.
5. Разрешите PHP запись в `storage/files` и `storage/logs`. Начните с прав 0750/0755 для каталогов; точные права зависят от пользователя PHP на хостинге.
6. Откройте `http://ps1.system404-sites.ru/mio/`. Дополнительная сборка и Composer не нужны.

Вместо phpMyAdmin можно выполнить `php tools/install.php --demo` через SSH. Скрипт без `--demo` создаёт только таблицы. База и пользователь создаются через панель хостинга; SQL не требует прав CREATE USER или CREATE DATABASE.

## Обновление предыдущего выпуска

Выпуск UI-kit от 22.10.2026 не меняет структуру БД. Новые признаки заполнения профиля хранятся в существующем JSON настроек. Миграция для этого выпуска не нужна. Если предыдущий полный выпуск уже установлен, замените файлы приложения, сохранив загруженные файлы в `storage/files` и свою локальную конфигурацию. SQL повторно импортировать не нужно.

Только при переходе с версии до 12.10.2026 импортируйте `database/upgrade_20261012.sql`, затем замените файлы приложения. Скрипт сохраняет аккаунты, назначения, приёмы и загрузки; повторный запуск допустим. Не импортируйте seed.sql поверх имеющихся данных. Новые чистые базы устанавливаются по инструкции выше.

## Возможности

- RU/EN интерфейс, адаптация к телефону и планшету, уменьшение анимации, поиск разделов через Ctrl/Cmd K.
- Тёмный лендинг с неоновой челюстью, зубным созвездием и пятью этапами маршрута; мерцающие звёзды, CSS 3D-модель челюсти и звёздный спутник. Кокпит с механической рамкой, топливом, опытом и навигацией; настоящие WebGL-планеты, голографическая сетка, кольца и перелёты ракеты.
- Регистрация по телефону, почте и паролю, затем предложение заполнить профиль; отдельные поля клиник, подсказка требований к паролю и показ пароля. Регистрация пациента или специалиста, вход, восстановление пароля через настроенную почту, приглашение пациента врачом с временными данными.
- Персональные задания на нескольких планетах, таймер, отметка занятий, запись с камеры, загрузка видео и комментарий врача.
- Дневник за неделю/месяц, CSV отчёт, отправка отчёта команде, фотопротокол с сопоставлением двух снимков.
- Совместное ведение пациента, история приёмов, диагнозы, аппараты, рекомендации, документы, направления и подтверждение факта консультации.
- Переписка пациента с врачами своей команды и внутренние уведомления.
- Направления врачу вне сервиса, согласие зарегистрированного пациента через код приглашения, вложения конкретного приёма, клиника и сроки лечения.
- Образование, интересы, несколько клиник, координаты для поиска рядом, отдельная видимость телефона/почты/соцсети и дипломов.
- Отзывы с согласием автора и модерацией, отдельная страница контактов, публичные материалы, обложки и английский контент CMS.
- Голосовая подсказка после образца по выбору пользователя (зависит от доступных голосов браузера).
- Админка: блокировка аккаунтов, верификация дипломов, библиотека упражнений и видео, палитры планет, контент, дополнительные страницы/меню, ссылки на инструменты и журнал действий.

## Видео и shared-хостинг

Загрузка готового видео работает на HTTP и HTTPS. Камера браузера требует HTTPS или localhost. После включения сертификата измените `app_url` в `config.local.php` на HTTPS. MP4 наиболее совместим; WebM зависит от браузера, MOV — от кодека. Приложение не перекодирует видео на shared-хостинге.

Лимит приложения: видео 80 МБ, фото 12 МБ, документы 15 МБ. В панели PHP задайте `upload_max_filesize=80M`, `post_max_size=100M`, `max_execution_time=120`, `max_input_time=120`, если тариф это позволяет. Сервер может задавать меньший предел. Лимит можно уменьшить в конфигурации.

## Почта и напоминания

Внутренние уведомления работают сразу. Для писем включите `mail.enabled`, укажите разрешённый отправитель домена и настройте доставку PHP mail у хостера. Письма получают пользователи, включившие email в профиле. Восстановление пароля также использует этот канал. Отправка SMS/MAX в этот выпуск не подключена: для неё нужны провайдер и его ключи.

Для напоминаний назначьте cron, например в 19:00 по Москве: `php /полный/путь/mio/tools/reminders.php`. Один пользователь получает не больше одного напоминания в день.

## Доступ и файлы

На Apache должны действовать включённые `.htaccess`: папки app, database, tools, tests, docs, demo и storage закрыты от прямых запросов. `media.php` проверяет сессию и права перед каждой выдачей файла, включая Range запросы видео. Если хостер использует Nginx без чтения `.htaccess`, добавьте аналогичные запреты в панели/конфигурации сервера; не размещайте приватное хранилище без этих правил.

Новые упражнения назначает и проверяет верифицированный миотерапевт. Ортодонт и миотерапевт добавляют фотографии. История доступна активной команде; направленный специалист получает доступ после подтверждения приёма. Пациент видит свои назначения и фотопротокол, а клиническая история приёмов находится в кабинете специалистов.

Пароль базы хранится только в локальной конфигурации, которая исключена из Git. Сессии используют HttpOnly/SameSite cookies, формы — CSRF токен, запросы к БД — подготовленные выражения. Приложение не требует внешних CDN.

## Проверки и структура

В выпуске 22.10.2026 полный тестовый прогон и проверка браузером не выполнялись по просьбе заказчика. Результаты в `docs/QA.md` относятся к предыдущему выпуску.

Серверные сценарии проверяются через PHP/MySQL, интерфейсные — через Happy DOM с настоящими HTTP-запросами. WebGL-шейдеры проверяются через Mesa EGL/GLES2. Итоговые числа и результаты находятся в `docs/QA.md`. Полная геометрия страниц в реальном браузере и физическая камера в этой среде не проверялись.

`tests/smoke.py` проверяет серверные сценарии через настоящий PHP HTTP сервер и MySQL. Требует отдельную тестовую базу, Python 3 и PHP; запускается с `MYO_TEST_PHP` и `MYO_TEST_MYSQL_COMMAND`. Команда создаёт тестовые БД `myoskills_test` и `myoskills_upgrade_test`, поэтому её не запускают с рабочим подключением.

`app/` — серверные обработчики и права; `assets/` — стили, модули JS и графика; `database/` — SQL; `tools/` — CLI установка и напоминания; `docs/` — описание архитектуры и итог проверок. Промпты графики сохранены в `assets/images/prompts.json` и `assets/images/hologram-prompts.json`. Шрифты TT Firs Neue и PT Root UI подключены локально. Сведения об источниках и лицензиях — в `assets/fonts/NOTICE.txt`; PT Root UI — OFL, TT Firs Neue — коммерческая лицензия TypeType.

Онлайн-оплата и автоматическая медицинская проверка AI оставлены для развития. Подтверждение выполнения в этом выпуске делает врач.
