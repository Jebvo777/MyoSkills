# MyoSkills

Рабочий кабинет пациента и специалистов: назначения, запись и загрузка видео, проверка выполнения, дневник, фотопротокол, история приёмов и совместное ведение. PHP 8.1+ с PDO MySQL, mbstring, fileinfo, MySQL 5.7+, Apache. Все шрифты, изображения и движок графики находятся в проекте. Node на хостинге не нужен.

## Замена существующего приложения

1. Сохраните копию рабочей базы и каталога сайта. Отдельно сохраните **config.local.php и storage/files/**: это конфигурация и реальные загруженные материалы.
2. В phpMyAdmin выберите существующую БД и импортируйте `database/upgrade_20261027_mysql57.sql`. Повторный импорт допустим. Старый SQL-дамп повторно не импортируйте.
3. Удалите старые файлы приложения и загрузите содержимое каталога `site/` из архива. Затем верните свою конфигурацию и весь каталог `storage/files/` из резервной копии. В комплекте замены уже сохранена конфигурация из предоставленного архива; файлы, появившиеся после него, необходимо перенести с сервера.
4. Проверьте соответствие `base_path` и `app_url` фактическому URL. `storage/files/` и `storage/logs/` должны быть доступны для записи PHP (обычно 0755/0775 в зависимости от хостинга; не 0777).
5. Откройте сайт заново, чтобы загрузились обновлённые модули. Войдите с реальным аккаунтом. Если использовался только прежний тестовый администратор, создайте администратора командой `php tools/create_admin.php ваша-почта` через SSH/терминал хостинга. Пароль вводится интерактивно; общих паролей нет. Команда не меняет роль существующего аккаунта.
6. Администратор добавляет настоящие упражнения и видео, а миотерапевт назначает их пациентам. Исходные тестовые упражнения отключены, история назначений сохранена. Не включайте пустое упражнение до заполнения его содержания.

Локальная конфигурация, резервные копии, дамп и файлы пациентов не публикуются в GitHub. Веб-доступ к `app`, `database`, `storage`, `tools`, `docs` закрывается приложенными `.htaccess`; эти файлы нужно переносить вместе с остальными. При Nginx настройте соответствующие запреты в конфигурации сервера.

## Новая установка

Скопируйте `config.example.php` в `config.local.php`, заполните параметры БД и URL. Выполните `php tools/install.php` либо импортируйте сначала `database/schema.sql`, затем `database/defaults.sql`. Установка создаёт только таблицы и общие данные шести планет, без пользователей и клинических записей. Создайте администратора командой выше. Регистрация специалиста требует проверки его документов администратором.

## Настройка сервиса

- HTTPS нужен для защищённых сессий и записи с камеры.
- Для восстановления пароля настройте рабочую почту (`mail.enabled`, `mail.from`) и отправку PHP mail на хостинге.
- Контакты организации, документы, услуги и условия доступа редактируются в разделе администратора. Незаполненные контакты не подменяются вымышленными данными.
- Напоминания: запускайте `php tools/reminders.php` по cron один раз в день.
- Лимиты PHP `upload_max_filesize` и `post_max_size` должны соответствовать `uploads` в конфигурации.
