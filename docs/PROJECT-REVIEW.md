## Найдено

- `demo_labels` включает тестовые входы и вымышленные отзывы; пароль зашит в клиентском обработчике.
- Администратор сохраняет тестовое видео, когда настоящий образец не загружен; `media.php` подменяет отсутствующие файлы тестовыми.
- В предоставленном дампе есть восемь исходных тестовых пользователей и реальные новые аккаунты. Миграция не должна очищать таблицы или выбирать аккаунты только по числовому ID.
- Тестовые упражнения могли быть назначены реальным пациентам. Их нужно отключить и очистить тестовый материал, сохранив историю, затем заменить в админке настоящими упражнениями.
- `cockpitDashboard` использует другой HUD и 3D-планету вместо статического зуба из макета.
- Звёздный проводник сейчас представляет собой взрослую проволочную фигуру. Референс заказчика — бело-фиолетовый астронавт с тёмным визором и светящимся лицом.
- Одни иллюстрации используются в маршруте, услугах, формах и кабинетах. Нужны назначения по слотам без повторного использования смысловых картинок.

## Решения по реализации

- Визор собирается из исходных слоёв Figma 48:331: чистый фон 1672 × 941, зуб 480 × 480, индикатор опыта 235 × 235, углы прицела, шкала, стрелка и сигнал. Полный скриншот интерфейса не используется как фон с запечёнными данными.
- Числа, выбранное упражнение и переходы берутся из кабинета текущего пациента. Надпись «Текст кнопки» заменяется рабочим действием.
- Тестовые учётные записи и материалы архивируются адресно; реальные данные и клиническая история не удаляются. Для владельца предусмотрено создание настоящего администратора без общего пароля.
- У каждого смыслового иллюстративного блока собственный файл. Для одного и того же объекта каталога сохраняется его идентичность; служебные иконки интерфейса остаются общими.
- Астроробот по приложенному референсу получает локальную объёмную модель с движениями суставов, лица и взгляда. Голографический человек отдельно получает детские пропорции и рост около 110 см.

## Границы проверки выпуска

Полный регресс, нагрузочное тестирование и запуск миграции на рабочем сервере в этот выпуск не входят. Доступ к серверу и рабочей БД не предоставлен. После упаковки выполняются проверки парсинга PHP/JS/JSON и целостности ZIP; результат фиксируется отдельно. Секреты, исходный SQL-дамп и данные пациентов в GitHub не публикуются.
