# Границы проверки выпуска от 27.10.2026

По запросу заказчика сначала формируется полный архив замены, затем выполняются только базовые проверки синтаксиса. Этот документ описывает объём проверки; он не подтверждает, что команды уже выполнены. Фактический результат фиксируется отдельным отчётом после упаковки.

## Базовые проверки после упаковки

- Парсинг PHP-файлов без исполнения приложения.
- Парсинг собственных JavaScript-модулей без запуска браузерных сценариев.
- Чтение JSON-метаданных и проверка целостности подготовленного ZIP.

Если синтаксическая ошибка требует исправления, исправленный комплект упаковывается заново, а соответствующая базовая проверка повторяется. В итоговом отчёте должен быть указан фактически проверенный архив.

## Что не заявляется

В текущем выпуске не заявлены полный регрессионный прогон, выполнение миграции на MySQL 5.7, проверка рабочих записей на сервере заказчика, нагрузочные испытания, проверка камеры на физических устройствах, доставка почты у хостера или полная браузерная проверка всех разделов.

Результаты прежних выпусков не служат подтверждением проверки изменённого кода. Старые количества пройденных сценариев в документацию текущего выпуска не переносятся.

## Состояние миграции

`database/upgrade_20261027_production.sql` подготовлен по структуре приложенного дампа и исходному коду. Используются конструкции MySQL 5.7: условные изменения схемы через `information_schema` и `PREPARE`, временные таблицы, InnoDB и обычные транзакции. Скрипт не требует процедур, MySQL 8 или удаления клинических записей.

Исходные аккаунты и материалы определяются точными признаками и архивируются. Совместимость конструкции SQL и чтение дампа не равны запуску миграции на рабочем сервере. Перед её импортом владелец сохраняет актуальную резервную копию и создаёт настоящего администратора по [DEPLOYMENT.md](DEPLOYMENT.md).

## Хостинг

Конфигурация Apache, права записи в хранилище, действующее подключение MySQL, HTTPS и доставка почты зависят от сервера владельца. Они задаются при установке. Проверка синтаксиса не подтверждает эти параметры и не изменяет рабочую БД.
