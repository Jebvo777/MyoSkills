# Проверки MyoSkills

Проверено 77 серверных сценариев и 33 сценария интерфейса.

## Среда

PHP 8.3.6, MariaDB 10.11.14, настоящий PDO MySQL, HTTP с префиксом /mio. JavaScript формы и переходы проверены в Happy DOM 21.0.1 с живым PHP API. Все PHP файлы и семь модулей JS проходят синтаксические проверки.

## Подтверждённые сценарии

- Регистрация, сессии, временный пароль врача, смена пароля, CSRF, блокировка аккаунта и защита от смены роли через регистрацию.
- Права пациента, ортодонта, миотерапевта и смежного специалиста; история по направлению доступна после подтверждения приёма.
- Назначения на разных планетах, открытие и приостановка конкретного упражнения, таймер и журнал выполнения.
- Загрузка видео настоящим multipart-запросом, закрытая выдача, HTTP Range, ограничения формата, проверка с комментарием и возврат на повторение.
- Награды без повторного начисления при двойной отметке занятия или повторной проверке видео.
- Фотопротокол, сравнение снимков, записи приёмов, документы специалиста и административная верификация.
- Диалоги команды, внутренние уведомления, недельные и месячные отчёты, CSV экспорт.
- Лендинг, переключение языка, фильтр специалистов, кабинеты пациента/врача/администратора, страницы CMS и формы сохранения.
- Доступность локальных ассетов и запреты на прямой доступ к приватным папкам в тестовом роутере.

## Границы проверки

Happy DOM проверяет взаимодействия и содержимое DOM; он не воспроизводит геометрию настоящего браузера. В этой среде не проверялись запись реальной камерой, отображение на физических устройствах, доставка email у хостера и конфигурация Apache на system404-sites.ru. Приложение на внешний хостинг не развёртывалось. Правила Apache включены в архив; камера требует HTTPS. SMS/MAX, оплата и автоматическая медицинская проверка AI в этот выпуск не входят.

## Повторный запуск

Используйте отдельную тестовую базу и команды из README. Серверный отчёт сохраняется в tests/runtime/report.json, отчёт UI — в tests/runtime/ui-report.json. В Git и установочный архив временные файлы тестовой среды не включаются.
