# Сверка MyoSkills с материалами

Основа: ТЗ, презентация, ответы на уточняющие вопросы и палитра пользователя. Уточнённые права и ручная проверка врачом определяют поведение первого выпуска.

| Требование | Реализация |
|---|---|
| MyoSkills, широкий интерфейс, заданная палитра | Лендинг и кабинеты, адаптация к телефону/планшету |
| Планеты как группы упражнений | Шесть отдельных миров, свои цвета и изображения, WebGL-поверхности |
| Переходы между планетами | Выбор мира, перелёт ракеты, переход к доступной следующей миссии после отправки видео |
| Сложность открывает миотерапевт | Индивидуальные назначения; опыт не разблокирует упражнения |
| Видеообразец, самостоятельное выполнение | Просмотр, шаги, таймер, журнал и опциональная голосовая подсказка |
| Видео пациента | Загрузка MP4/WebM/MOV, запись MediaRecorder на HTTPS, предварительный просмотр, индикатор загрузки |
| Проверка врачом | Подтверждение или повторное выполнение с комментарием; защита от повторной проверки |
| Игровой прогресс | Топливо, XP, звёзды, ранги, серия дней; защита от дублирования наград |
| Фотопротокол | Загрузка ортодонтом/миотерапевтом, даты, галерея и сравнение снимков |
| История приёмов | Врач, дата/время, диагноз, аппарат, метод, рекомендации, план, следующий приём и вложения |
| История закрыта пациенту | Проверка активной команды на сервере; клинические документы не выдаются пациенту |
| Смежные специалисты | Направления по специальности, поиск имени, уведомления и подтверждение консультации |
| Врач вне базы | Ручное направление и запись результата направившим врачом, без выдачи доступа внешнему лицу |
| Добавление пациента врачом | ID-код и временный пароль; для существующего аккаунта — приглашение с подтверждением пациента |
| Самостоятельная регистрация | Пациент/врач; позднее принятие кода приглашения в профиле |
| Сроки, клиника и план лечения | Редактирование ортодонтом/миотерапевтом или администратором |
| Разные роли специалистов | Отдельные серверные ограничения для назначений, проверки видео, фотографии и расширенного плана |
| Верификация | Дипломы, административная модерация и значок подтверждённого профиля |
| Профиль | Контакты, соцсеть, образование, интересы, несколько клиник и координаты |
| Приватность | Отдельная публикация почты/телефона/соцсети, добровольная видимость дипломов |
| Поиск специалистов рядом | По городу, специальности и координатам; врачи без координат не получают выдуманное расстояние |
| Дневник и отчёт | Неделя/месяц, CSV, отправка команде |
| Связь | Личные диалоги, внутренние уведомления, опциональная почта и cron-напоминания |
| Лендинг | Метод, интерактивная челюсть, этапы маршрута, услуги, планеты, рассказ спутника, отзывы, FAQ |
| Контакты и дополнительные инструменты | Отдельные страницы, контакты в футере, редактируемые внешние ссылки |
| CMS | Страницы и меню, обложки, RU/EN содержимое, изображения/PDF, библиотека видео, планеты и отзывы |
| Shared-хостинг | PHP 8.2+, PDO MySQL, Apache, подпапка /mio, без сборки и фонового Node-сервера |
| Передача | GitHub, архив, SQL схемы и тестового наполнения, миграция предыдущей версии |

## Что не подключено

Онлайн-оплата отложена по ответу №9. SMS/MAX не отправляются без выбранного провайдера и его подключения. Автоматическая клиническая AI-проверка из раннего слайда не реализована: в уточнённом сценарии видео проверяет миотерапевт. Для её отдельной реализации нужны критерии оценки упражнений и согласованный сервис обработки видео.

Реальные медицинские видео, фотографии, документы сервиса и контактные сведения заполняет владелец проекта. В seed.sql используются обозначенные демонстрационные материалы и вымышленные отзывы; они не изображают результаты лечения.

Реальная камера, доставка писем, геометрия страниц в браузере и настройки внешнего хостинга требуют проверки после установки. Серверные сценарии, DOM-взаимодействия, миграция и 3D-шейдеры проверены в среде разработки.
