# Рабочий режим

Быстрые входы, общий пароль, вымышленные отзывы, резервные тестовые медиа и режим конфигурации удалены из приложения. Сессия и форма входа также отвергают зарезервированный домен исходных аккаунтов независимо от старой локальной конфигурации.

Миграция для существующей MySQL 5.7 сохраняет исторические внешние ключи. Она блокирует только исходные адреса в зарезервированном домене, скрывает их связи, отключает тестовые упражнения и архивирует три точных тестовых файла. Это позволяет сохранить реальные аккаунты и медицинскую историю без массового удаления. Колонка вымышленных отзывов удаляется условно, через information_schema/PREPARE. Подмены отсутствующего видео больше нет: интерфейс показывает отсутствие образца.

Новая установка не создаёт учётных записей. Администратор создаётся с индивидуальным паролем. В реальном каталоге отображаются только действующие подтверждённые специалисты.
